# 💰 Income-Expense Tracker

โปรแกรมบันทึกรายรับ-รายจ่ายแบบ Terminal เขียนด้วย Python

## คุณสมบัติ
- บันทึกรายรับ/รายจ่าย (ชื่อ, หมวดหมู่, ประเภท, จำนวนเงิน)
- ดูประวัติรายการทั้งหมด
- แก้ไขและลบรายการ
- ค้นหาตามหมวดหมู่ พร้อมสรุปยอดรวม
- แสดงยอดเงินคงเหลือทุกครั้งที่เปิดเมนู

## วิธีรัน
```bash
python main.py
```
ต้องใช้ Python 3.x ไม่ต้องติดตั้งไลบรารีเพิ่ม

## เมนูการใช้งาน
| เมนู | หน้าที่ |
|---|---|
| 1 | บันทึกรายการ |
| 2 | ดูประวัติ |
| 3 | แก้ไขรายการ |
| 4 | ลบรายการ |
| 5 | ค้นหาหมวดหมู่ |
| 6 | ออกจากโปรแกรม |

## ตัวอย่างการใช้งาน
```
💰 ยอดเงินคงเหลือ: 0 บาท
เลือกเมนู (1-6): 1
ชื่อรายการ: เงินเดือน
หมวดหมู่: งาน
ประเภท (in/out): in
จำนวนเงิน: 15000
 บันทึกแล้ว!
```

## โครงสร้างโปรแกรม
| ฟังก์ชัน | หน้าที่ |
|---|---|
| `get_balance(items)` | คำนวณยอดคงเหลือ |
| `add_item(...)` | เพิ่มรายการ |
| `show_all()` | แสดงรายการทั้งหมด |
| `edit_item()` | แก้ไขรายการ |
| `delete_item()` | ลบรายการ |
| `search_cat()` | ค้นหาและรวมยอดตามหมวดหมู่ |

## เกณฑ์ที่ตอบโจทย์
1. **Interactive menu & input**: เมนู 1-6 ใน `while True`
2. **Data structure**: list ของ dictionary (`data`)
3. **Conditional logic**: `if/elif/else`
4. **Loop**: `for`, `while`
5. **Functions**: แยกหน้าที่เป็นฟังก์ชัน
6. **Algorithm**: linear search, accumulator
7. **Validation**: ชื่อไม่ว่าง, ตัวเลขเท่านั้น, จำนวน > 0, เงินพอจ่าย, `try/except`
8. **Functional application**: ใช้ติดตามรายรับรายจ่ายได้จริง
